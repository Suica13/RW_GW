# RW_GW_BU
RW高达战争_战争宇宙Mod

Main/主包
用于存放通用信息和各类模板，且处理开始游戏的部分事件和单位
也包括部分标记用单位和通用计算用单位
(例如地图类型标记，TileMode检测发送单位，单位通用计算核心单位与伤害计算单位）

DLC/分包
用于存发系列别的单位，科技树，开始单位（基地等）
由于铁锈自己不能跨mod读取文件，所以在修改通用模板后请及时覆盖至Main/主包与其他DLC/分包中。
（例如技能模板/通用的光束军刀格斗武器模板/动画模板/通用子弹图片音效等）

备忘
如果要加入BGM请不要在每个包里都加入，这会导致体积翻倍
音乐文件和音效文件统一用.ogg(请不要直接改后缀名，用格式工厂或别的软件转译为准)
图片文件统一用.png
模板文件全部用.gw扩展名
